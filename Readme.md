Download the latest release of the MS Access Clone as a ZIP file.
Create a new folder and move the ZIP file into it.
Extract all the contents of the ZIP file.
Delete the ZIP file (optional).

Open the extracted folder and navigate to inside of Win32 folder.
Double-click MsAccessClone.exe to launch the application.
Enjoy using the application!
Notes
This application was developed in Delphi 13.
No installation is required; the program runs directly from the extracted folder.
This project is intended as a temporary database management solution and is not designed to replace Microsoft Access permanently.
